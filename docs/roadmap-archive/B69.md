# B69 — `glass-meter` is overloaded: move the secondary readouts into a details popup
*Archived roadmap item — Bugs. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Fixed (07/2026).** The `glass-meter` card stacked up to seven lines (icon, value+unit, rate, error, status, reading-age, raw) in one small tile.

**Fix (mirrors glass-light / glass-lock).** The card now keeps only the **primary** readout — icon + big value + unit, plus the **fault badge** (a fault must stay visible) and the label. The **secondary readouts** (rate ↗, status, reading-age, raw) moved into a **details popup** opened by the corner **⋯** button, using the shared `FeezalGlassCard` + `glassPopupStyles` infrastructure. The element now extends `FeezalGlassCard`; the ⋯ button appears only when a secondary readout is enabled (`show-rate`/`show-status`/`show-timestamp`/`show-raw`); the card stays display-only (no toggle). Bundled the B68 width fix (removed the `.card { position: relative }` override).

**Ships with:** `test-browser/feezal-glass-meter.test.js` (card keeps value+unit + ⋯ button; popup lists rate/status/updated; a fault stays on the card) + updates to the shared `feezal-meter-cards.test.js` (glass-meter opens the popup for the rate/status assertions). Patch-bumped `feezal-element-glass-meter` (→ 0.1.3).

**Relates:** B68 (the width bug on the same element — fixed together), glass-lock / glass-light (the ⋯-popup pattern + `FeezalGlassCard`/`glassPopupStyles`), glass-value (the decluttered value card this resembles), E147 (the AI-on-the-edge meter this card serves).
