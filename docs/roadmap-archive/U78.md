# U78 — Generate wizard: a room-review step before the device review ✅ done
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**Requested & done (07/2026).** On the **room** axis the App generator now inserts a **Rooms** step between the axis/family setup and the device review — you review the *rooms* first, not the devices.

**What it does.**
- The room list is derived from auto-detection (`groupForApp(eligible, 'room')` minus the Unassigned fallback), each room carrying its lexicon match `words` + icon.
- Each room row has: a **drag handle** (HTML5 drag-drop reorder), the shared **icon picker** (`feezal-icon-input`), an editable **name**, **↑/↓** buttons, and an **✕** remove. An **Add a room…** input appends a room (its label folded for matching, picking up lexicon synonyms if it names a known room). Duplicate labels are rejected (they key the list and become view slugs).
- **Order is the drawer order** — reorder here and the device review + generated `layout-app` drawer follow it (`_reviewBuckets` sorts rooms by the room-list index, Unassigned last).
- On **Review devices…**, every device is re-assigned to the edited list via `assignRoom` (U76 fold + prefix + bounded-substring match against each room's `words` ∪ its folded label; a trusted `suggested_area` naming a room wins). A device whose room was **deleted** is re-scanned against the **remaining** rooms and lands in a match (including a freshly **added** room) or in **Unassigned**.
- The **function** axis skips the step (its groups are the fixed taxonomy, not editable rooms).

**Implementation.** `feezal-generate-dialog.js`: a new `'rooms'` stage + `_renderRooms`, `_rooms` state (built by `_buildRoomsFrom`, edited by `_removeRoom` / `_addRoom` / `_renameRoom` / `_moveRoom` / `_setRoomIcon` + the drag handlers), `_startReview` routing (room → `_toRooms`, function → `_toReview`), and a room-axis branch in `_toReview` that assigns via the new `assignRoom` / `lexiconWordsForLabel` in `feezal-discovery-stamp.js`. Unit-tested (`assignRoom` / `lexiconWordsForLabel`: lexicon-word match, custom-label match, area precedence, empty list) and browser-tested (build list, remove→re-scan→Unassigned, add→re-claim, up/down + drag reorder → review order, duplicate-rename guard, function axis skips).
