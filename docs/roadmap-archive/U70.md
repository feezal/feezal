# U70 — Review: "＋ Create new room" in the per-device move-to-room dropdown ✅ done
*Archived roadmap item — Usability & UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** In **room** mode, each device's move-to-room `<select>` ends with a **`＋ Create new room…`** sentinel option. Choosing it opens a small **editor-dark-mode-aware** `sl-dialog` (`class="newroom"`, stacked above the wizard via a higher `--sl-z-index-dialog`) with a name input; **Create** (or Enter) moves that device into the new room via `_reassign` (a brand-new label springs the bucket into being with a default icon) and the room becomes selectable in every other device's dropdown. **Cancel** / an empty name leaves the device put; a name matching an existing bucket **merges** rather than duplicating. Function mode has no create option — its buckets are the fixed E138 taxonomy.

⚠️ **Sentinel value gotcha (B86 lesson):** the sentinel is `'__feezal_new_room__'`, deliberately ASCII with no space/NUL — a NUL (or a space that becomes one) inside an `<option value>` attribute is mangled by the HTML parser to U+FFFD, so the change handler never matched it. Keep it plain ASCII.

Browser-tested: the sentinel opens the dialog without reassigning, and confirming a (trimmed) name moves the device into the new bucket — `test-browser/feezal-generate-dialog.test.js`, `describe('U70 …')`.
