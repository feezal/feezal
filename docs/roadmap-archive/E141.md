# E141 — Metro tiles: per-state background colour vars for state-driven elements
*Archived roadmap item — Element ecosystem. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** The background sibling of [E140](E140.md). For the Metro family the **tile background** is the primary state signal, so every state-driven metro tile now exposes a **dedicated per-state background var** — the *primary* state no longer silently reuses the generic `--feezal-metro-accent`.

**Before.** Per-state overrides existed for the *secondary* states (`--feezal-metro-off-color`, `-open-color`/`-tilt-color`, `-active-color`, `-unlocked-color`/`-jammed-color`), but the **primary** state of every tile (on / closed / clear / locked) painted the bare `--feezal-metro-accent` with no dedicated name — so an author couldn't set "background when ON" independently of the family accent.

**Added** (each defaults to `var(--feezal-metro-accent)`, so untouched dashboards — and ones that set `--feezal-metro-accent` — are pixel-identical; the state selector was made explicit in CSS):
- **metro-switch / metro-light** → `--feezal-metro-on-color`
- **metro-contact** → `--feezal-metro-closed-color`
- **metro-motion / metro-sensor** → `--feezal-metro-clear-color`
- **metro-lock** → `--feezal-metro-locked-color`

`--feezal-metro-accent` stays the family's tile colour and the on/primary default (themes key off it) — E141 just exposes the per-state override explicitly so authors aren't forced to repurpose the generic accent. Purely additive.

**Deliberately out of scope.** **metro-climate** and **metro-cover** have **no** per-state tile background today (climate is always accent regardless of mode; cover paints a position-fill overlay, not a state background). Giving them per-mode / open-closed backgrounds is a **new visual behaviour**, not "expose an existing state colour as a var" — tracked separately if wanted, not part of this item.

**Ships with:** the per-state background-var additions across the six state-driven metro tiles, patch bumps on each touched package, a browser test (`test-browser/feezal-metro-state-colors.test.js`: each tile exposes its per-state vars and the primary-state var defaults to the accent), and a TESTING.md note.

**Relates:** [E140](E140.md) (the icon-colour sibling — the circle reference and the glass gap), E114 (parity — same background knobs across metro tiles), E137 (controllers own default per-state semantics for contact/motion/sensor/lock), `MetroTileBase` (`--feezal-metro-accent` + `.face`), §5.1 theme-variable discipline, E129 (metro tile sizing/typography — same family chrome).
