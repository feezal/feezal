# U62 — Normalize discovered names into friendly labels on stamping
*Archived roadmap item — Near-term Improvements. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** Autodiscovery now stamps a **friendly `label`** instead of the raw device/entity name, so a discovered element reads *"Licht Hobbyraum"* rather than *"licht_hobbyraum"* or *"OC8 Hobbyraum:14"*.

**`friendlyName(raw)` helper** ([www/src/feezal-discovery-stamp.js](../../www/src/feezal-discovery-stamp.js)), rules in order:
1. **Strip a trailing Homematic channel suffix** — only a trailing `:<digits>` (`…:14` / `…:0`), never a colon elsewhere (`12:30 Timer` is left alone).
2. **Underscores → spaces**, whitespace runs collapsed.
3. **Capitalize the first letter of each all-lowercase word**; a word that already carries an uppercase letter is left entirely alone, so acronyms/units survive (`kWh`, `CO2`, `WLED` unchanged; `licht` → `Licht`).
4. **Idempotent** — `Wohnzimmer Lampe` passes through unchanged.

**Wiring — one place, all sources.** Applied centrally in `stampDiscovery`: any value routed to the `label` attribute is normalized, so it covers **native (Homematic/WLED), Home Assistant and zigbee2mqtt** uniformly and fires identically in the **⚡ picker and the Generate wizard** (both share `stampDiscovery`). No per-controller map edits were needed.

**zigbee2mqtt topic fallback.** When no usable name produced a label — missing, or just the platform (`name === entity.component`, e.g. "switch") — the label is derived from the **base topic's last segment** and normalized (`zigbee2mqtt/licht_hobbyraum` → **"Licht Hobbyraum"**).

**Scope / edges.** Label text only — not topic values, discovery ids, or the entity's internal name. The N12 "don't clobber an edited label on re-sync" guard stays the caller's concern; `friendlyName` being idempotent means re-stamping is safe.

**Ships with:** `friendlyName` + the stamp wiring (incl. the topic fallback and the platform-name skip); unit tests in `test/feezal-discovery-stamp.test.js` (trailing `:N` stripped; underscores→spaces; per-word capitalization; acronym/unit preservation; z2m topic fallback; idempotency; empty/nullish); three E108 stamp-label assertions updated to the normalized values; a TESTING.md note.

**Relates:** U58 (Generate wizard — shares `stampDiscovery`), the ⚡ discovery picker (the other caller), `feezal-discovery-stamp` (where it hooks), E146 / E147 (z2m + meter names benefit), N12 (re-sync must not clobber edited labels), E108 (native recognizers supply the raw `config.name`).
