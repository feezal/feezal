# E7 — Swipe gesture element
*Archived roadmap item — Element ecosystem. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** `feezal-element-system-swipe` — a **pseudo-element** (invisible in the viewer, a small "Swipe" placeholder on the canvas) that enables swipe-to-navigate between views on touch devices. Pairs with the viewer's mobile/kiosk use.

**Behaviour.** Listens for pointer gestures on the viewer root (`window` pointerdown/pointerup). On a directional **touch** swipe past `threshold`, it navigates the view cycle via `feezal.site.view = …` — the same path the navbar / basic-navigation use. Guards:
- **Touch only** — a mouse drag never navigates (`pointerType === 'touch'`).
- **Axis + threshold** — the dominant delta must be ≥ `threshold` px AND ≥ 1.3× the cross-axis delta, so a diagonal gesture over scrollable content is ignored (scroll-safe).
- Wraps past the ends (`wrap`, default on); `direction` picks horizontal/vertical; `views` restricts/orders the cycle (empty = all `feezal-view` children in order).
- `animate` (default on) slides/fades the incoming view in via the Web Animations API on the active view element (self-contained, no global CSS), suppressed under `prefers-reduced-motion`.

**Attributes** (exactly as speced): `views`, `direction` (horizontal|vertical), `threshold` (px, default 50), `animate` (bool), `wrap` (bool).

**Ships with:** the element + package registration + manifest; a browser test (`test-browser/feezal-system-swipe.test.js`: next/prev, wrap on/off, threshold, diagonal rejection, vertical axis, explicit `views` order, a real touch-pointer gesture, the mouse-drag no-op, and the editor placeholder vs. viewer-invisible split); a TESTING.md §6 row.

**Relates:** U13 (viewer mobile support — the natural pairing), basic-navigation / material-navbar (the `feezal.site.view` navigation path reused), the dialog pseudo-elements (same invisible-placeholder editor convention), A18 (kiosk/wall-panel touch use).
