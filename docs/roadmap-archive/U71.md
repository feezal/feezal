# U71 — Generate wizard: illustrate the element families with screenshots ✅ done
*Archived roadmap item — Usability & UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** The App step-1 family control (which U69 gave a whole screen to breathe) is now a **gallery of thumbnails** instead of text buttons: one bundled screenshot per family, the selected one framed in the primary colour with its label bolded; a family without an image falls back to a placeholder tile + the label.

- Images live in [`www/src/family-shots/`](../../www/src/family-shots/) (`glass.png`, `metro.png`, `circle.png`, author-provided) and are pulled in as **Vite asset imports** (`import glassShot from './family-shots/glass.png'`) — each is emitted as a hashed asset in the editor chunk, **self-hosted per A25** (no external request), lazy-loaded (`loading="lazy"`), and cropped to a uniform 4:3 tile with `object-fit: cover`.
- Adding a family's preview is just: drop `<family>.png` into `family-shots/` and add one line to the `FAMILY_SHOTS` map in `feezal-generate-dialog.js`. Families that ship discovery elements but have no image still appear (placeholder + label), so the picker never hides a choice.
- Scoped to App step 1 (the roomy screen); the Devices tile keeps its compact text family buttons.

**Relates:** **U69** ✅ (the step-1 screen this enriches), **U58** / **U67** ✅ (the wizard), **A25** ✅ (bundled, no CDN), `_renderApp` + the `.fam-gallery` / `.fam-card` styles + `FAMILY_SHOTS` in `feezal-generate-dialog.js`.
