# E161 — HA discovery: consume friendly names, icons, and areas ✅ implemented
*Archived roadmap item — Element Ecosystem. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented (07/2026).** All three parts landed on top of [B89](B89.md)'s nested-`device` expansion.

**1. Friendly names in the ⚡ picker.** `discoveryLabel()` (`www/src/feezal-discovery-stamp.js`) now prefers the device's friendly name (`config.device.name`, e.g. "Lichterkette Ida") over the raw MQTT topic, so a discovered device reads **"Lichterkette Ida relay"** instead of `esphome/…/relay/state`. The U56 per-attribute suffix still disambiguates one device's many entities under that name ("Sensor Cellar temperature" / "… humidity"). Falls back to the topic-based label when no device name is present (native recognizers keep their `<source>: <name>` form).

**2. Auto-stamp the icon — when feezal has it.** A curated `mdi:*` → Material Symbols alias table (`www/src/mdi-to-symbols.js`, 80 mappings, every value verified against the installed Symbols set) drives a new `mdiIcon` stamp transform. The value cards' discovery map gains `icon: {attr: 'icon', transform: 'mdiIcon'}` **after** the E160 `device_class` mapping, so a discovered `mdi:blur` → `blur_on` **overrides** the device_class icon; an `mdi:*` name with no alias is **skipped** (the E160 device_class icon, then the element default, stands) — never passed through verbatim to render blank. Added to `circle-value` and `glass-value` (E160's set — the only value cards that render an icon).

**3. Areas → the Generate wizard (U58).** `getDeviceGroups()` (`server/src/mqtt/discovery.js`) now captures `group.area` from `device.suggested_area` (`sa`) / top-level `suggested_area`. Not consumed by any element — it is metadata for U58's future per-area app generation. Exposed on `/api/discovery/device-groups`.

**Tests:** `www/test/mdi-to-symbols.test.js` (every alias is an installed Symbol; keys are prefix-free; the reported ESPHome icons are covered), `www/test/feezal-discovery-stamp.test.js` (device-friendly-name label + suffix; `mdiIcon` hit / unmapped-miss→device_class fallback / no-device_class→unset / no-device_class→discovered icon), `server/test/discovery.test.js` (area captured from `sa`; null when absent). `docs/TESTING.md §2` row added. Patches: circle-value 3.2.7, glass-value 3.0.14.
