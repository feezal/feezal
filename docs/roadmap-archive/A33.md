# A33 — Move element-only toolkit deps out of `www/package.json` into their families ✅ done
*Archived roadmap item — Architecture & Infrastructure. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** Follow-up to [A32](A32.md) — the four remaining design-system toolkits that sat in `www/package.json` but were imported **only** by element packages are now declared by those packages, so a standalone `npm install @feezal/feezal-element-x` resolves without relying on the app hoisting the widget.

**Moved** (declared in the importing package's `dependencies`, removed from `www/package.json`):

| dependency | now declared in | count |
|---|---|---|
| `@material/web` (`^2.4.1`) | 5 circle (`circle-climate/-cover/-fan/-humidifier/-light`) + 12 material (`material-button/-checkbox/-chip/-fab/-icon-button/-input/-progress/-radio/-select/-slider/-switch/-time-picker`) | 17 |
| `@carbon/web-components` (`^2.58.1`) | `carbon-button/-checkbox/-input/-select/-slider/-switch` | 6 |
| `leaflet` (`^1.9.4`) | `feezal-element-material-map` | 1 |
| `lottie-web` (`^5.13.0`) | `@feezal/feezal-lottie` (the shared lazy-loader — the ONE real `import('lottie-web')` site; `basic-lottie` / `system-splash` consume it through that internal package, not directly) | 1 |

**Stale deps pruned** from `www/package.json`: `html5sortable` (the editor's flow reorder no longer uses it — removed from `node_modules`) and `flatpickr` (no importer anywhere; it remains only as a transitive dep of another package, which is correct — not ours to declare).

**Guard drained.** `www/test/package-declared-deps.test.js`'s `GRANDFATHERED` set is now **empty** — the A32 ratchet's second test confirms the list stays honest, so nothing element-only can be hoisted to `www/package.json` again without failing CI. `npm install` re-linked (workspace hoists to the same `node_modules`, so bundle/resolution are unchanged — this is a provenance fix, not a layout change); build + full www unit suite (1179) green. All 25 touched element packages patch-bumped per policy.

**Explicitly NOT in scope (moved to a separate item):** the broad dependency *refresh* (in-range `npm update` + the out-of-range majors: vite 8, marked 18, date-fns 4, dragselect 3, …) and the `npm ci` / lockfile-enforcement / supply-chain hardening. Those touch `server/`, the workflows and the Dockerfile — outside A33's `www/package.json` remit — and are tracked in **A34**. Also still out of scope: the workspace-internal `@feezal/*` under-declaration (most element packages don't declare even `@feezal/feezal-element`), a distinct convention question.

**Relates:** [A32](A32.md) ✅ (the parent — its guard + grandfather list this drains), **A34** (the dependency-refresh + supply-chain work split out of this item), `www/test/package-declared-deps.test.js`, `scripts/release.js` (publishes the packages that must resolve standalone), A23/A24 (family externalization — a family that declares its own toolkit dep is one step closer to shipping standalone).
