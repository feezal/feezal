# U73 — Welcome wizard: fork into "explore the editor" vs "just autogenerate an app" ✅ done
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**Done (07/2026).** The U37 tour (`feezal-welcome-tour.js`) gained a **fork** right after the basics and a second branch. The linear `STEPS` array is now navigated over a **path-filtered view** (`_steps()` + `_path`): a fork step (two choice buttons, no Next) sets `_path` to `explore` or `auto`; step membership is by three sets (`ALWAYS` = welcome/terminology/fork, `EXPLORE_ONLY`, `AUTO_ONLY`; the shared broker/status/deploy steps show once a path is chosen).

- **Explore path** — the existing hands-on sequence, unchanged (palette → canvas → inspector → theme → broker → status → deploy → drop → wire → template → finish).
- **Autogenerate path** — skips the UI/hands-on steps: broker → status → deploy → a **discovery-wait** step (polls `/api/discovery/devices` every 2.5 s, with a persistent *"No devices yet? Skip to the editor"* bail-out) → a **generate** step that opens the Generate dialog at the App tile and **suspends the tour overlay** (renders nothing so it never covers the modal), resuming once the dialog reaches its `result` stage (or ending in the editor if the user closes it without generating) → a **finale** spotlighting Deploy and mentioning ▾ → View + Export.

This resolved the two U58 §Onboarding decisions as the roadmap flagged: the autogenerate path **waits** for discovery (with the bail-out) and **drives** the Generate dialog (suspend/resume around the modal). The explore branch keeps the simple spotlight finale. Editor-only throughout — nothing reaches the viewer/export bundle.

**Requested (07/2026).** [U37](U37.md) ✅ is one linear hands-on sequence. Add a branch after the basics so a first-run user picks their path:
1. After the terminology / basics steps, a fork asks: *"Place a few elements yourself"* (explore) or *"Just autogenerate an app from your devices"*.
2. Explore path — the existing hands-on sequence, unchanged.
3. Autogenerate path — skip the manual element steps. Guide only the MQTT connection, then wait until the connection is established AND devices are discovered, then open the Generate → App flow.
4. After the app is created, a final step points to the viewer + mentions export.

**Ships with:** the fork step + two branches, the tour-overlay/dialog hand-off (suspend/resume), the empty-discovery bail-out, browser tests (fork routes correctly; auto path skips the UI/hands-on steps; discovery advances to Generate once devices exist; the bail-out lands in the editor; the Generate step is suspended and opens the dialog at the App tile; the finale points at Deploy/export), a `docs/TESTING.md` update, and U37's editor-only property preserved.
