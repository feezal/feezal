# U64 — `layout-app`: expanding the slim rail must not push the content ✅
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** Expanding a slim/edge rail now **overlays** the content instead of pushing it: the rail is taken out of flow (`position:absolute`) and `.content` reserves the rest width with a `margin-left` gutter, so the reveal grows over the view — the embedded view does not shift. New **`rail-expand`**: `overlay` (default, this request) · `push` (the old in-flow grow, kept) · `never` (icon rail only). Reveal is `:host(...) .drawer:hover, ...:has(:focus-visible)` — a pointer/tap never expands the rail (no focus-pinning), only hover and keyboard focus do. **`rail-menu-button`** (default off) puts a hamburger at the TOP of the rail (the app bar may not exist under `header: never`/`small-only`) that opens the full drawer as an overlay — reusing the narrow-mode scrim/Esc/close-on-select. Both honoured by slim AND edge rails. Naming unified with B84 onto the `rail-*` axis. Browser tests assert the overlay layout (drawer absolute + content margin) vs push, and the rail-menu overlay incl. `header: never`. Applies alongside the B84 rail model; patch: layout-app 3.0.16.

---

**Requested (07/2026):** at a screen width that shows the **slim rail**, expanding it to the wide menu should **overlay** the content — the embedded view must stay exactly where it is, not shift sideways.

**Cause.** The rail and the content are siblings in the same flex row: `.drawer` is `flex: 0 0 auto` and `.content` is `flex: 1`. So `width: 64px → var(--feezal-app-drawer-width, 220px)` on hover/`:focus-within` takes ~156px away from the content, which reflows and re-wraps every tile under it. The expansion is currently a **layout** change; it needs to be a **paint** change.

```
now                          wanted
┌────┬───────────────┐       ┌────┬───────────────┐
│rail│  content      │  rest │rail│  content      │
├────┴──┬────────────┤       ├───────┬────────────┤
│ menu  │ content    │  open │ menu ▓│ content    │   content unmoved,
└───────┴────────────┘       └───────┴────────────┘   menu drawn over it
        ↑ content pushed
```
