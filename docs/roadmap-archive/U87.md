# U87 — Element outline / layers panel ✅ done
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented (08/2026).** `www/src/feezal-sidebar-layers.js` — its **own sidebar
tab**, right after the Inspector (it first shipped as an inspector tab; the reporter
pointed out that a site-wide navigator does not belong inside the per-element
inspector, and the tree below only makes sense with the full height of a panel).

**A tree of the whole site:** every view is a collapsible node with its element count,
and only the currently open view is expanded — a 20-view site stays readable. Any node
can be expanded or collapsed by hand, including collapsing the current one. Elements are
listed top-most first (reverse paint order) with palette icon, label, topic hint and a
lock toggle.

**Fuzzy filter** (`www/src/feezal-fuzzy.js`, ~40 dependency-free lines rather than
pulling in fuse.js): matches element type, label and both topics, ranking substring hits
above scattered subsequences and word-boundary hits above buried ones. A query surfaces
matches **across all views** — views with hits auto-expand, views without are hidden —
so "temp" finds every temperature card in the site, and "ktemp" still finds "Kitchen
temperature".

Click selects and scrolls the element into view, switching views first when the element
lives elsewhere; Ctrl/Shift extend exactly like the canvas. The selection is read from
the canvas's own `feezal-selected` class rather than plumbed in as a property, so it
cannot drift from what the canvas shows. Drag restacks within a view (never across
views), one undo step. A MutationObserver on the SITE keeps the tree live, so palette
drops, deletions, pastes, new views and Generate runs all appear without any cooperation
from those call sites. Only each view's direct children are listed — real nesting arrives
with U3 grouping. Tests: `test-browser/feezal-sidebar-layers.test.js`,
`test/feezal-fuzzy.test.js`, `test-e2e/align-layers.test.js`.

For dense views: a collapsible tree of the current view's elements (icon, label/tag, topic hint), click = select (scroll into view), drag = restack, per-row lock toggle; multi-select with ctrl/shift mirroring canvas selection. Complements U3 grouping (groups would nest). Not started — 💡 discuss priority; the inspector sidebar already has a tab structure to host it.
