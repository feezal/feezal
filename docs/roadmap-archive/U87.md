# U87 — Element outline / layers panel ✅ done
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Implemented (08/2026).** `www/src/feezal-sidebar-layers.js`, a Layers tab in the inspector: the current view's elements top-most first (list order = reverse paint order), each row carrying the palette icon, label, topic hint and a lock toggle. Click selects and scrolls the element into view; Ctrl/Shift extend exactly like the canvas, and the canvas selection is mirrored back. Drag a row to restack (one undo step). The panel owns a MutationObserver on the view, so palette drops, deletions, pastes and Generate runs show up without any cooperation from those call sites. Only the view's direct children are listed — real nesting arrives with U3 grouping. Tests: `test-browser/feezal-sidebar-layers.test.js`, `test-e2e/align-layers.test.js`.

For dense views: a collapsible tree of the current view's elements (icon, label/tag, topic hint), click = select (scroll into view), drag = restack, per-row lock toggle; multi-select with ctrl/shift mirroring canvas selection. Complements U3 grouping (groups would nest). Not started — 💡 discuss priority; the inspector sidebar already has a tab structure to host it.
