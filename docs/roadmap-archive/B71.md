# B71 — `system-splash` appears to do nothing in the viewer (was per-view, not site-wide)
*Archived roadmap item — Bugs. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Fixed (07/2026).** The splash "only worked on the view where the element was placed" — the reporter expected it site-wide.

**Root cause.** The splash is an invisible pseudo-element, but its `position: fixed` overlay lived inside its `<feezal-view>`, which is `display: none` while another view is active (views toggle `display`, N26). A `position: fixed` element in a `display: none` subtree isn't rendered — so a splash on a non-initial view never covered boot.

**Fix.** On viewer connect, the splash **hoists itself to `document.body`** (`this._portaled` guard; re-enters `connectedCallback` with `parentNode === body`), so its overlay escapes the view and covers the whole site regardless of which view holds it. Because it's an invisible pseudo-element, its DOM position is irrelevant. The place-once + settle/hide lifecycle is unchanged. In tests the element mounts directly under `document.body`, so it doesn't move (the existing tests are unaffected).

**Ships with:** `test-browser/feezal-element-system-splash.test.js` — hoists out of a `display:none` container to `document.body` with the overlay `position: fixed`; a no-move case when already under body. Patch-bumped `feezal-element-system-splash` (→ 0.1.2).

**Deferred (optional polish, not blocking).** Even site-wide, on a fast load the overlay is imperceptible — its background defaults to `--primary-background-color` (page colour) and the spinner only appears after `spinner-delay` (1000 ms). Making it observable (spinner sooner, a subtly-distinct default background, an editor "Preview splash") is a separate visibility tweak, intentionally not bundled here (changing `spinner-delay` trades off the fast-load no-flash behaviour).

**Relates:** E39 (`system-splash` origin — FOUC/boot cover), `feezal-app-viewer` / `feezal-site` (the view `display` toggle this works around), the viewer boot/connection lifecycle (`feezal.connection` `connected`/`message` events the hide rides on), B70 (sibling System-element polish).
