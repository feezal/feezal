# B66 — Glass badges (battery / unavailable) overlap the card label
*Archived roadmap item — Bugs. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Fixed (07/2026)** in `feezal-element-glass-climate`.

**Symptom.** On a `glass-climate` card with a low-battery warning, the battery icon sat at the bottom-left and overlapped the card label ("Thermostat Schlafzim…"). The label is flow content in the footer while the badges are absolutely positioned in the same bottom band, so nothing reserved space for them.

**Fix.** Reserved a bottom strip (`.card { padding-bottom: 15px }`) and dropped the battery + unavailable badges to `bottom: 2px`, so they sit **below** the label instead of overlapping it — in both the stacked and the wide (`min-aspect-ratio: 2/1`) layouts.

**Other glass elements (checked, left as-is).** `glass-wled` / `glass-cover` / `glass-light` also bottom-position `.unavail`, but use a different layout (an absolutely-positioned, centred bottom label over a control ring; mains devices, no battery badge). Low collision risk in practice, so untouched to avoid regressing those layouts. If a long ellipsised label ever reaches the bottom-right `.unavail` there, the clean fix is to move `.unavail` to a top corner (as `glass-contact` already does) — a small follow-up, not part of the reported bug.

**Relates:** E124 (battery badge), N31 (unavailable badge), E114 (family parity), [B67](B67.md) (the sibling badge-parity bug — circle-climate battery + metro availability), `feezal-element` (`feezalBatteryStyles` / `batteryLowBadge`).
