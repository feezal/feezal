# B74 — View theme selector: rename the default entry "Site theme (default)" → "Inherit" and drop its colour swatch
*Archived roadmap item — Bugs. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Fixed (07/2026).** In the view theme selector the default (empty) entry was labelled "Site theme (default)" and showed a neutral colour swatch like the real themes.

**Fix.**
1. **Renamed to "Inherit"** — scoped to the view picker. The shared `feezal-theme-select` only shows the empty entry in **element-mount mode** (the per-view picker; the site-theme sidebar sets `.options` without `.element`, so it has no empty entry). The view theme attribute descriptor ([feezal-view.js](../../www/src/feezal-view.js)) now declares `emptyOption: 'Inherit'`, and the inspector's custom-control mount ([feezal-sidebar-inspector-attributes.js](../../www/src/feezal-sidebar-inspector-attributes.js) `_renderCustom`) forwards `.emptyOption` to the mounted control.
2. **No swatch for the empty entry** — `_renderSwatch('')` in `feezal-theme-select.js` now renders nothing (both the dropdown row and the closed/selected display), so "Inherit" reads as a plain, distinct default choice. Real themes (and the built-in `default`) keep their compound swatch.

**Ships with:** the descriptor + forwarding + swatch suppression, and a browser test in `test-browser/feezal-theme-select.test.js` (the empty entry shows "Inherit" with no `.swatches`; a real theme still renders its swatch).

**Relates:** U57 (the compound-swatch theme picker this tweaks), U53 (the shared styled picker), B50 (the `emptyOption` contract), the per-view theme attribute (U51).
