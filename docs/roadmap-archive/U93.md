# U93 — Top-bar improvements: MQTT dot into the sidebar, labeled Generate/Source buttons, site switcher left ✅ done
*Archived roadmap item — Editor UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**Requested (08/2026).** Three changes to the editor top bar.

## 1. MQTT status dot moves into the sidebar

The standalone `#mqtt-dot-btn` is gone from the top bar. The state now rides as a small badge on the **Site Settings** tab icon in the right-hand sidebar tab bar — the tab that opens the Connection settings — in the same four states and colours as before (green connected, red configured-but-failed, pulsing amber while a deploy applies the connection, grey unconfigured).

**Placement was the one real decision here.** The item said "the sidebar tab-bar icon of the Connection tab (the sl-tab-group in the viewer sidebar)", which points at two different places: the always-visible outer tab bar, or the `Connection` sub-tab *inside* the Site Settings panel. Badging the sub-tab is the literal reading but defeats the dot's entire purpose — passive at-a-glance status is worthless if you must open a panel to see it. Confirmed with the requester: outer tab bar.

The click-to-open behaviour comes free, as predicted: the badged button is the Site Settings tab, so clicking it opens the panel that holds Connection. The state label is folded into that tab's tooltip (`Site Settings — MQTT: connected to ws://…`), so nothing is lost by dropping the dedicated button. `_mqttDot()` — the state mapping — is untouched, so its existing unit tests still apply.

## 2. Generate and Source are labeled buttons

Both now carry their icon plus a text label. They stay flat `icon-btn`s rather than becoming solid pills like Deploy/View: they are toolbar actions, not the bar's primary calls to action, and three pills beside Deploy would have flattened that hierarchy. All existing states are kept — Generate hides in source mode, Source keeps its active styling and the syntax-error badge beside it.

## 3. Site switcher left, toolbar after it

`feezal-site-manager` now leads the centre cluster, with the copy/paste/cut/delete/undo/redo toolbar following it. Final order: palette toggle · site switcher · toolbar · Generate · Source · Deploy · View.

**Verified** in a real editor: no `#mqtt-dot-btn` anywhere, the badge geometrically inside the Site Settings icon with the right state class and merged tooltip, clicking it opening Site Settings, the labeled buttons rendering their text, and the centre cluster in the intended order.

**Relates:** U60 (connection overlay — untouched, only the passive dot moved), N15 (source-mode button), U58 ✅ (Generate button), U87 (established the sidebar tab-bar pattern).
