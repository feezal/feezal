# U69 — Generate wizard: the review IS the selection (drop the flat first page) ✅ done
*Archived roadmap item — Usability & UX. Open items: [../ROADMAP.md](../ROADMAP.md) · Index: [README.md](README.md)*

**✅ Done (07/2026).** App mode no longer has a flat device checklist before the review — the grouped review IS the selection surface.

- **Step 1 (`_renderApp`) is now just the axis (By room / By function) + the element family**, with a "N devices discovered" note and a **Review …** button. No device list.
- **`_toReview` selects every generatable device by default** (`_checked` = all eligible) and buckets them; the review renders a **checkbox per device** (checked) plus a **bucket-header checkbox** (toggle a whole room, indeterminate on partial), all driven by U68's range/drag select. The user **unticks** what they don't want.
- **`_generateApp` acts only on checked devices** — `bucket.entities.filter(e => _checked.has(e.__key))`; a bucket the user emptied creates no view. The footer "Generate app (N views)" and the count reflect only checked devices.
- Bucketing / room detection, rename-to-merge, per-device reassign and the "guessed" markers are unchanged — only the selection moved here.

**Devices mode** (flat place-onto-current-view) is a separate tile and keeps its own list — untouched. Browser-tested: `_toReview` selects all eligible, and unchecking a device excludes it (and empties its view) in `test-browser/feezal-generate-dialog.test.js`, `describe('U69 …')`; the existing idempotent-re-run test updated to uncheck after `_toReview`.
