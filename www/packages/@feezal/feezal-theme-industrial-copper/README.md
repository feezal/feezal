# Industrial Copper for feezal

Warm metallic dark theme - copper and bronze on deep charcoal, with warm-tuned state colours and glass-family tokens. Original re-implementation inspired by the German Home Assistant community's "industrial_copper" theme ([simon42 forum thread, post #7](https://community.simon42.com/t/luxus-home-assistant-dashboard-wie-auf-dem-bild-umsetzbar/89304/7) by user Mercator). The brushed-metal card texture of the original needs family surface/shadow tokens and will follow separately.
